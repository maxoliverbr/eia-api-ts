Quick start

Grab a free key at eia.gov/opendata, then:

Run the server

# install & configure
bun install
cp .env.example .env
# set EIA_API_KEY in .env

bun dev
# → http://localhost:3000/openapi

Query anything

curl -X POST localhost:3000/query \
  -H 'content-type: application/json' \
  -d '{
    "domain": "coal",
    "route": "aggregate-production",
    "frequency": "annual",
    "data": ["production", "price"],
    "start": "2020",
    "end": "2024"
  }'

More examples

Discover first, then query. Every endpoint is plain HTTP.

Search by topic

curl -X POST localhost:3000/search \
  -H 'content-type: application/json' \
  -d '{"q": "solar"}'
# → domains, routes, tags, example queries

List domains

curl localhost:3000/domains
# → 15 domains with useCases + exampleQuery

Fetch the agent playbook

curl localhost:3000/guide
# workflows, decision trees, recipes

Filter by facet

curl -X POST localhost:3000/query \
  -H 'content-type: application/json' \
  -d '{
    "domain": "electricity",
    "route": "retail-sales",
    "frequency": "monthly",
    "data": ["price"],
    "facets": {"stateid": ["TX"], "sectorid": ["RES"]}
  }'

Typed client (Eden Treaty)

import { treaty } from '@elysiajs/eden'
import type { App } from './src'

const api = treaty<App>('localhost:3000')
const { data } = await api.domains.get()

Run the bundled examples

bun run examples/02-discovery.ts
bun run examples/06-query-post-basic.ts
bun run examples/agent-usage.ts

OpenAPI, out of the box

Every route is generated from its TypeBox schema, so the spec never drifts from the code.

Browse & fetch the spec

# Swagger UI
open http://localhost:3000/openapi

# OpenAPI 3.1 JSON
curl localhost:3000/openapi/json > spec.json

Generate a client in any language

bunx openapi-typescript spec.json -o api.d.ts
bunx @openapitools/openapi-generator-cli \
  generate -i spec.json -g python -o ./client

Plug into any MCP client

Set MCP_ENABLED=true and the same surface is exposed at /mcp as 9 tools and 2 resources.
