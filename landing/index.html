Quick start

Grab a free key at eia.gov/opendata, then:

Run the server

# install & configure
bun install
cp .env.example .env
# set EIA_API_KEY in .env

bun dev
# → http://localhost:3000/openapi

Query anything

curl -X POST localhost:3000/query \
  -H 'content-type: application/json' \
  -d '{
    "domain": "coal",
    "route": "aggregate-production",
    "frequency": "annual",
    "data": ["production", "price"],
    "start": "2020",
    "end": "2024"
  }'

Plug into any MCP client

Set MCP_ENABLED=true and the same surface is exposed at /mcp as 9 tools and 2 resources.
