## Programmatic discovery

If you don't want to hard-code domain ids, discover them at runtime:

```bash
curl http://localhost:3000/domains | jq '.domains[] | {id, name, subRoutes: (.subRoutes | length)}'
```

Or search by intent:

```bash
curl -X POST http://localhost:3000/search \
  -H 'Content-Type: application/json' \
  -d '{"q": "monthly electricity generation by fuel"}' | jq '.hits[].path'
```

See [Discovery](/concepts/discovery/) for the full loop.
