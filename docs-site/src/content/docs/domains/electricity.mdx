## Facets

<Aside type="caution">
  State identifiers vary by route: `location` accepts a state name (e.g.
  `"CALIFORNIA"`); `stateid` is a 2-letter code (e.g. `"CA"`).
</Aside>

| Facet id | Casing | Example values |
|---|---|---|
| `location` | lowercase | `"US-TOTAL"`, `"CALIFORNIA"`, `"TEXAS"` |
| `stateid` | lowercase | `"CA"`, `"TX"`, `"NY"` |
| `sectorid` | lowercase | `"RES"`, `"COM"`, `"IND"`, `"TRA"` |

## Agent guidance

- **Default endpoint for "electricity generation by state/fuel" questions**:
  `electric-power-operational-data`.
- **Frequency is monthly** by default for these routes.
- **`fueltypeid` values are short codes** — `"NG"` for natural gas, `"NUC"`
  for nuclear, `"SUN"` for solar, `"WND"` for wind. Always list the
  facet first.
