## Common patterns

Every agent that uses the wrapper should:

1. **Fetch `/guide` once at startup** — use it as the system prompt.
2. **Use the canonical 5-step loop** — search → inspect → facet → resolve →
   query. See [Multi-step agent](/guides/multi-step-agent/).
3. **Handle the four error classes** — 422 / 400 / 502 / 401. See
   [Error handling](/guides/error-handling/).
4. **Cache `/guide`** — it has a 1-hour TTL on the server; fetch once per
   session, not per call.
5. **Trust the metadata** — the wrapper's domain metadata carries `agentHints`,
   `taskToRoute`, `columnDescriptions`, and `agentGuidance`. Read these
   before guessing.

## When to use which pattern

| Pattern | When |
|---|---|
| **Mastra + OpenRouter** | You need an LLM to interpret free-text user intent and route to the right dataset. |
| **Ontology-first** | You have structured concepts ("Coal emits CO₂") and want to map them to EIA domains without an LLM. Also great for LLM agents that benefit from a reasoning scaffold. |
| **MCP client** | You're building (or using) an MCP-compatible client — Claude Desktop, Cursor, custom. |
